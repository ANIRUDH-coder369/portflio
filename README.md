# Anirudh Sontakke - Portfolio

Modern personal portfolio website and backend API.

## Live Deployments
- **Frontend (Client)**: [https://portflio-6pt8.vercel.app/](https://portflio-6pt8.vercel.app/)
- **Backend API (Server)**: [https://portflio-ten-beta.vercel.app/](https://portflio-ten-beta.vercel.app/)

## Tech Stack
- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, Redux Toolkit
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT, bcryptjs

## Project Structure
- `client/`: Next.js frontend application
- `server/`: Express.js backend API
